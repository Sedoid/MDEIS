Objective: By the end of the lesson, learners can read a bar chart and state two facts that the chart shows.

## Introduction
Show a bar chart of the number of books borrowed from the school library in each month. Ask what we can tell at a glance.

## Activities
1. Learners copy the chart and write the height of each bar beside it.
2. Pairs write two true statements about the chart, for example which month had the most books borrowed.
3. Joel Achu will help me hand out the chart paper and then work with the group near the window.
4. Each pair reads one statement and the class checks it against the chart.

## Check for understanding
A new chart with four bars. Learners write two facts it shows and one question it cannot answer.
